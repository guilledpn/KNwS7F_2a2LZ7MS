# Evidencia técnica histórica

Esta carpeta conserva informes fechados de validaciones, ejecuciones y cambios ya realizados.

## Autoridad

Los archivos de evidencia demuestran qué ocurrió en un momento determinado. No son procedimientos vigentes ni redefinen estándares, contratos o reglas de negocio.

Para conducta actual, consultar:

- `AGENTS.md` para enrutar el trabajo;
- `docs/engineering/development-standards.md` para desarrollo y calidad;
- `docs/operations/` para procedimientos vigentes;
- Arquitectura y Modelo del Dominio para contratos e invariantes.
